# Customer Churn Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing customer churn behavior using data analytics and visualization techniques. The objective is to identify patterns and factors contributing to customer churn and derive actionable insights that can help improve customer retention strategies.

Using Python, SQL, and visualization libraries, the project performs data preprocessing, exploratory data analysis (EDA), and churn pattern analysis on a structured customer dataset.

---

## 🚀 Features

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Customer churn trend analysis
* SQL-based querying and aggregation
* Data visualization using charts and graphs
* Business insights generation for decision-making

---

## 🛠️ Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* SQL (SQLite/MySQL)
* Jupyter Notebook

---

## 📂 Dataset

The dataset used for this project contains customer demographic information, account details, service usage patterns, and churn labels.

Dataset Source:
IBM Telco Customer Churn Dataset

---

## 📊 Analysis Performed

The project includes:

* Handling missing values and duplicate records
* Feature engineering and data transformation
* Churn distribution analysis
* Contract type and churn correlation
* Monthly charges and tenure analysis
* Customer segmentation based on churn behavior

---

## 📈 Visualizations

Some of the visualizations included in the project:

* Churn distribution plots
* Contract type vs churn analysis
* Monthly charges distribution
* Tenure analysis
* Correlation heatmaps

---

## 🧠 Key Insights

* Customers with month-to-month contracts showed higher churn rates.
* Higher monthly charges were associated with increased churn probability.
* Customers with longer tenure were less likely to churn.
* Certain service usage patterns strongly influenced customer retention.

---

## 🗄️ SQL Queries

SQL was used to:

* Aggregate customer statistics
* Analyze churn across customer segments
* Identify high-risk customer groups
* Extract insights from structured data efficiently
